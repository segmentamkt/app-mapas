# Videos renderizados

Los `.mp4` de esta carpeta se pueden descargar directamente desde GitHub:
abrí el archivo y usá el botón **Download raw file** (o "Descargar").

Cada archivo se genera con:

```bash
npm run render -- data/videos/<archivo>.json
```

y el resultado queda en `out/`. Los que valga la pena conservar se copian acá.
